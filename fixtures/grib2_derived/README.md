# Derived GRIB2 Fixtures

This directory stores reproducible GRIB2 fixtures derived from the committed NOAA
and JMA inputs under `fixtures/grib2_noaa/` and `fixtures/grib2_jma/`.

The corpus includes:

- `wgrib2`-rewritten fixtures for scan-order and bitmap-reuse edge cases
  including scalar `scan32` / `scan48` and U/V-pair `scan32` / `scan48`
  inputs for `-new_grid`
- deterministic synthetic forecast-series fixtures generated by
  `cmd/main/main_wbtest.mbt`
- deterministic synthetic `-netcdf` fixtures, including mixed-reference,
  spherical Mercator, spherical Mercator mixed-reference, rotated lat-lon,
  polar stereographic, and Lambert conformal inputs generated by
  `cmd/main/main_wbtest.mbt`
- real-value forecast-series fixtures generated from committed JMA MSM inputs

They are used to move scan-order and bitmap-reuse compatibility cases into the
committed validation corpus without depending on a separate external download,
and to keep forecast-processing compares (`-ncep_norm`, `-merge_fcst`,
`-unmerge_fcst`) on committed synthetic and real-world input sets
(`TMP:1000 mb`, `UGRD:1000 mb`, `VGRD:1000 mb` across `FH00-15`, `FH18-33`,
`FH18-33 long`, `FH36-39`).

Regenerate locally with:

```bash
WGRIB2_BIN=${WGRIB2_BIN:-/opt/homebrew/bin/wgrib2} \
  bash tools/update_derived_grib2_fixtures.sh
```

See `manifest.tsv` for the source fixture and derivation command for each file.
